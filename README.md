## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project will run locally using Vite.
